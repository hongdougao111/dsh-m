# CODING-STANDARDS.md — dsh-m 编码与测试纪律

实现与评审共读，**评审 Agent 以此为准绳**（实现侧由评审把门，不占实现上下文）。
来源：ADR-0021 配套实施计划三轮独立评审（2026-10-15）沉淀的方法论条款。

## 测试锚纪律（构建产物的两条物理事实）

本仓库构建（`scripts/build.mjs`）有两个非默认设定，衍生两类**确定性为假**的测试断言：

1. **`treeShaking: false`** —— 未调用的标识符同样进入 `lib/client.js`。
   ⇒ 禁止「bundle 中 grep 不到某标识符」类负向预言（未调用 ≠ 不在场）。
   差分/负向锚只用两种合法形态：**源结构锚**（grep `src/**`，如「解构 1 处 → 加调用点后 ≥2 处」）或 bundle 中 **ASCII 字面量**的在场/缺席。
2. **esbuild 默认 `charset=ascii`** —— bundle 内一切非 ASCII（i18n 中文、CSS 模板串内中文）转义为 `\uXXXX`（注释除外）。
   ⇒ **中文文案锚一律走源结构锚**；bundle 锚只允许 ASCII 字面量。

量化断言一律**出现次数语义**（`grep -o … | wc -l` 或 `str.split(锚).length - 1`），不用 `grep -c`（行数语义，随打包行合并漂移）。

## 客户端状态机约定

- 面板手势类逻辑（拖拽/resize/后续同类）一律拆 **DOM-free 纯逻辑模块**（`src/client/window-*.js`，ESM 具名导出，禁 `module.exports`）+ node:test 直测（契约锚 + 数学矩阵 + 存取语义三件套）。
- DOM 接线层（main.jsx 手势状态机）不写 node 单测，以 bundle/源锚 + 渲染冒烟覆盖；纪律逐条镜像既有先例（ADR-0017/0021：rAF 帧内写、手势帧零 setState、释放收口、setPointerCapture、主键门卫、多指守卫、卸载清理）。
- resize 拖拽路径**零动画**：不给 width/height/grid/flex-wrap 挂任何 transition（跟手 1:1 优先于装饰）。

## 行为零变化承诺（每特性必填格）

改动既有组件时，计划与 ADR 必须写明「缺省态/无记忆态与旧版的一致性口径」——几何一致、样式一致、DOM 节点数是否变化要分别如实声明；验收时按口径核验，不虚报「逐像素一致」。

## 证据纪律（计划与红线里的事实断言）

计划、语义等价红线、CHANGELOG 中关于「现状如何」的陈述，写入时就要有当场证据；四条全部可由评审执行：

- **行为断言必实测**：描述某输入今日的实际流转（函数返回值、钳制/floor 发生在哪层），以最小 `node -e` 探针或现有测试输出为据；读码推断的运行时行为按未验证处理。（0.9.92 红线 #3 两次写错教训：clamp 钳制值、clampLimit 归因。）
- **引用测试锚先读**：声称「某套件钉住 X」之前读过该文件当前版本；按文件名或记忆猜的锚按虚报处理。（0.9.92 计划曾虚称 tools-summary 有 systemPrompt 锚。）
- **行号锚写入即复核**：行段锚写进计划那一刻 grep 过现场——早前会话的行号按过期处理；消费时符号锚优先。（两役评审共抓出行号漂移 4+ 次。）
- **退出码卫生**：测试输出过管道（grep/head）时以 `set -o pipefail` 或显式 `$?` 消费测试进程退出码；grep 命中输出行 ≠ 测试通过。（0.9.93 A1 红测试曾被管道掩盖后 commit。）
